# 📊 Business Insights Report (EDA) using Python

🚀 **Business Insights Report** is a Python-based Exploratory Data Analysis (EDA) project that analyzes retail sales data to discover trends, evaluate business performance, and generate actionable insights through data visualization.

---

## 🛠️ Tech Stack
🐍 Python | 📊 Pandas | 🔢 NumPy | 📈 Matplotlib

---
